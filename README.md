# GymNotes

Мобильный дневник тренировок на русском языке. Статическое PWA без платных API, регистрации, сервера данных, внешних шрифтов или аналитики. Записи хранятся в localStorage на каждом устройстве отдельно.

## Возможности
- Свободная тренировка, каталог и собственные упражнения (повторения или секунды).
- Вес, подходы, заметки, предыдущий результат.
- Автосохранение незавершённой тренировки.
- История, поиск, графики последних 20 тренировок и рекорды.
- Таймер отдыха с абсолютным временем окончания, сохраняющийся после перезагрузки.
- JSON-экспорт и проверяемый импорт резервных копий.
- Manifest, иконки и Service Worker для установки и офлайн-доступа.

## Запуск
В этой папке выполните `python3 -m http.server 4173 --directory dist` и откройте http://localhost:4173. Node.js и сборка для работы приложения не нужны. Для автоматических тестов: `node --test tests/*.test.js`.

Для размещения на другом статическом хостинге загрузите содержимое `dist/` и включите HTTPS. Отдельной базы данных нет. Адрес сайта должен оставаться стабильным: данные привязаны к origin.

## На iPhone
Откройте опубликованный HTTPS-адрес в Safari → Поделиться → На экран Домой → Добавить. При наличии переключателя включите «Открывать как веб-приложение». Первый запуск выполните с интернетом; в настройках появится готовность к офлайн-работе. Затем открывайте дневник одной и той же иконкой.

Браузер и установленное PWA могут иметь разные хранилища. Переносите записи через Настройки → Скачать копию → Восстановить из файла. Очистка данных сайта, удаление приложения или управление хранилищем системой могут удалить записи. Регулярно сохраняйте JSON в «Файлы». Импорт заменяет дневник после подтверждения.

Таймер считает время корректно после возврата в приложение, но iOS может приостановить фоновый звук. Это не системный будильник. Объём — сумма веса × повторений, без упражнений на время; вес собственного тела не учитывается.

## Проверка
Автотесты проверяют расчёт объёма, подходы с собственным весом, допустимость ввода, целостность резервных копий и порядок истории. В браузере проверены создание, ввод, сохранение после перезагрузки, завершение, история и график на ширине 390 px. Настоящий iPhone и поведение офлайн в Safari требуют отдельной проверки на устройстве.

При изменении файлов приложения обновляйте версию CACHE в `dist/sw.js`. Новая версия активируется после закрытия старых вкладок.
